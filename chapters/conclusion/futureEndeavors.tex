\section{Trabalhos Futuros}

Um outro ponto interessante é a possibilidade de usar um \textit{framework} para criptografia de dados sensíveis diretamente do Vortex. A \textit{Integrity} é um framework \citep{costa2022integrity} para criptografia de dados através de ORM em aplicações \textit{back-end} que utilizam bases de dados relacionais. Através de uma camada de ORM com suporte a criptografia, algumas colunas específicas podem ser escolhidas para serem criptografadas diretamente pela aplicação. Dessa forma, os dados armazenados escolhidos estariam criptografados diretamente na base de dados e só podendo ser descriptografado por uma aplicação desenvolvida utilizando o Vortex.

O desenvolvimento de um sistema de \textit{pool cache} para resultados de \textit{queries} com \textit{triggers} na base de dados para invalidar os \textit{caches} sempre que alguma alteração ocorrer nas tabelas referentes as \textit{queries} especificas.

Utilização de técnicas como \textit{Generators} que permitem realizar \textit{loops} como \textit{foreach} sem a necessidade de armazenar um \textit{array} em memória, o que permitirá uma economia de recursos, principalmente no contexto do ORM.
